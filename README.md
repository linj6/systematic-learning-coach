# Systematic Learning Coach

跨领域系统化学习教练：通过知识地图、分层讲解、主动提问、实践验证、掌握度评估与长期复习，帮助学习者建立可解释、可应用、可检验的知识体系。

## 当前阶段

当前为 **V1.0 方法论初稿**，尚未发布可执行的 Skill。方法论来自 JVM、JUC、MySQL、Redis、RabbitMQ 等专项复习实践，后续将通过跨领域学习继续验证。

## 路线图

1. Review 方法论与教学决策规则。
2. 编写 `SKILL.md`、教学规范和文档模板。
3. 在软件工程专项学习中验证并迭代。
4. 扩展 AI、金融投资等领域适配器。

## 核心原则

先整体后局部；先理解后记忆；先独立思考后反馈；以实践和证据检验结论；按学习目标控制深度；归档材料必须能够脱离聊天记录独立阅读。
